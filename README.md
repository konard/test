# Антикоррупционный мониторинг

Система мониторинга и визуализации коррупционных дел с анонимизацией персональных данных согласно ФЗ-152 "О персональных данных".

## 🎯 Описание проекта

Веб-приложение для сбора, анализа и визуализации информации о коррупционных делах по регионам России. Система обеспечивает:

- ✅ Безопасное хранение данных с анонимизацией
- ✅ Интерактивную тепловую карту регионов
- ✅ Статистические графики и аналитику
- ✅ Ролевую модель доступа
- ✅ Импорт данных из CSV/Excel
- ✅ Журнал аудита действий

## 🏗️ Архитектура

### Технологический стек

**Backend:**
- Laravel 10 (PHP 8.1+)
- MySQL 8.0
- Spatie Laravel Permission (ролевая модель)
- Maatwebsite Excel (импорт/экспорт)
- Intervention Image (обработка изображений)

**Frontend:**
- Vue.js 3
- Leaflet (интерактивные карты)
- Chart.js (графики)
- Vite (сборка)

**Инфраструктура:**
- Hostia.net (хостинг)
- Composer (управление зависимостями PHP)
- NPM (управление зависимостями JS)

## 📋 Основные функции

### 1. Управление данными о коррупционных делах

- **Импорт:** CSV/Excel файлы с автоматической валидацией
- **Хранение:** Анонимизированные данные в MySQL
- **Анонимизация:** Автоматическое удаление ФИО, телефонов, email
- **Шифрование:** Исходные данные хранятся в зашифрованном виде

### 2. Визуализация данных

**Интерактивная карта (Leaflet):**
- Тепловая карта регионов России
- Цветовая индикация уровня коррупции
- Всплывающие подсказки при наведении
- Оптимизация для мобильных устройств

**Графики статистики (Chart.js):**
- Динамика по годам (линейный график)
- Топ-5 регионов (столбчатая диаграмма)
- Типы нарушений (круговая диаграмма)
- Статусы дел (кольцевая диаграмма)

### 3. Безопасность и конфиденциальность

**Ролевая модель:**
- `admin` - полный доступ ко всем данным
- `moderator` - доступ только к данным своего региона
- `guest` - публичные анонимизированные данные

**Защита данных:**
- Хеширование должностей (SHA256 + HMAC)
- Анонимизация описаний (автоматическое удаление ПД)
- Журнал аудита действий пользователей
- Соответствие ФЗ-152

## 🚀 Быстрый старт

### Требования

- PHP 8.1+
- MySQL 8.0+
- Composer
- Node.js 16+ и NPM

### Установка

1. **Клонирование репозитория:**
```bash
git clone https://github.com/xlabtg/test.git
cd test
```

2. **Установка зависимостей:**
```bash
composer install
npm install
```

3. **Настройка окружения:**
```bash
cp .env.example .env
php artisan key:generate
```

Отредактируйте `.env` и укажите настройки базы данных:
```ini
DB_DATABASE=anticorruption
DB_USERNAME=your_username
DB_PASSWORD=your_password
```

4. **Создание базы данных:**
```bash
php artisan migrate
php artisan db:seed
```

5. **Сборка фронтенда:**
```bash
npm run build
```

6. **Запуск сервера разработки:**
```bash
php artisan serve
```

Откройте в браузере: `http://localhost:8000`

## 📊 Структура базы данных

### Таблица `regions`
- `id` - ID региона
- `name` - Название региона
- `geojson` - Границы в формате GeoJSON

### Таблица `corruption_cases`
- `id` - ID дела
- `region_id` - Связь с регионом
- `position_hash` - Хеш должности (анонимизация)
- `violation_type` - Тип нарушения
- `date` - Дата нарушения
- `status` - Статус дела
- `description_anon` - Анонимизированное описание
- `original_data` - Зашифрованные исходные данные

### Таблица `users`
- `id` - ID пользователя
- `name` - Имя
- `email` - Email
- `password` - Хешированный пароль
- `region_id` - Регион (для модераторов)

## 🔐 Безопасность

### Анонимизация данных

Система автоматически удаляет из описаний:
- ФИО в формате "Иванов И.И."
- Номера телефонов
- Email адреса

Пример:
```
Вход: "Должностное лицо Иванов И.И. получил взятку"
Выход: "Должностное лицо получило взятку"
```

### Журнал аудита

Все действия пользователей логируются в `storage/logs/audit.log`:
```
[2024-11-04 10:30:15] USER:admin@example.com (ID:1) ACTION:imported_data PATH:admin/import IP:127.0.0.1 STATUS:200
```

## 📖 Использование

### Импорт данных

1. Войдите как администратор или модератор
2. Перейдите в `/admin/import`
3. Загрузите CSV/Excel файл со следующей структурой:

```csv
region,position,violation_type,date,status,description
Москва,Начальник отдела,взятка,2024-01-15,завершено,Описание дела
```

**Обязательные поля:**
- `region` - название региона (должно существовать в БД)
- `position` - должность
- `violation_type` - тип (взятка, злоупотребление, растрата, мошенничество, превышение полномочий, коммерческий подкуп, другое)
- `date` - дата в формате YYYY-MM-DD

### Просмотр карты

Откройте главную страницу `/` - интерактивная карта с регионами, окрашенными по уровню коррупции.

### Просмотр статистики

Откройте `/statistics` - графики с аналитикой по годам, регионам и типам нарушений.
